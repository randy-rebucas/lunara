## Full changelog

### Authentication & onboarding

- **Phone OTP via Twilio** — production SMS verification for sign-in and sign-up
- Email + password auth retained
- Guided onboarding (profile + first address)

### Booking & orders

- Full booking flow: service type, schedule, address, weight, add-ons, estimate
- **Promo codes** — apply/remove during booking with live discount on quote
- Order list with filters and history
- **Order detail payment summary** — method, status, amount, receipt code, cash timing
- Live tracking — timeline, rider location, delivery verification, handoff QR

### Payments & wallet

- Checkout via PayMongo (GCash, Maya, card), cash, or Lunara wallet
- **Wallet top-up** via GCash/Maya with PayMongo redirect flow
- Transaction history and balance view
- Improved cash payment handling at pickup/delivery

### Home & engagement

- Deals carousel on home screen
- Referral program promo card
- Active orders and quick actions on dashboard

### Notifications

- In-app notification inbox with mark-read and deep links
- Real-time updates via Socket.IO
- Push notifications (requires production EAS build + Firebase on API)

### Account & support

- Profile — name, avatar, phone, email, saved addresses
- Privacy policy & terms links (`https://lunara.app/privacy`, `/terms`)
- Support tickets, refund requests, lost-item reports, post-delivery reviews
- Share/invite from profile

### Release engineering

- EAS production build pipeline configured
- Store asset templates (8 screenshots per platform + feature graphic)
- Monorepo shared packages auto-built via `eas-build-post-install`
- New Architecture enabled (`newArchEnabled: true`)

## Build & submit commands

From `apps/customer-mobile`:

```bash
# Verify EAS secrets
eas secret:list

# Production builds (both platforms)
npm run eas:build
# or individually:
npm run eas:build:ios
npm run eas:build:android

# Submit latest builds to stores
npm run eas:submit
# or:
eas submit --platform ios --profile production --latest
eas submit --platform android --profile production --latest
```

Monitor builds at [expo.dev/eas](https://expo.dev/eas).

## Pre-release checklist

### Configuration

- [ ] `EXPO_PUBLIC_API_URL` points to production API (not localhost)
- [ ] Optional: `EXPO_PUBLIC_WEBSITE_URL` = `https://lunara.app`
- [ ] iOS APNs credentials configured (`eas credentials --platform ios`)
- [ ] Android signing key configured (`eas credentials --platform android`)
- [ ] Google Play service account JSON ready for `eas submit`

### Store listing

- [ ] Screenshots uploaded (templates in `store-assets/`)
- [ ] Feature graphic (Android 1024×500)
- [ ] Store copy from [STORE_LISTING_CUSTOMER_MOBILE.md](../../../docs/STORE_LISTING_CUSTOMER_MOBILE.md)
- [ ] Content rating questionnaire completed
- [ ] Privacy policy URL: `https://lunara.app/privacy`

### Device verification

- [ ] Sign in with phone OTP (Twilio)
- [ ] Complete onboarding → book → checkout (GCash/Maya/card/wallet/cash)
- [ ] Apply a promo code during booking
- [ ] Top up wallet via GCash or Maya
- [ ] Track order with live WebSocket updates
- [ ] Receive push notification (if Firebase configured)
- [ ] Create support ticket / refund request from Profile
