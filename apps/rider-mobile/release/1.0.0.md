## Full changelog

### Shift & dispatch

- **Go online / offline** — start and end shift from Home
- **Today's earnings** at a glance on Home
- **Task list** with filters (assigned, active, completed)
- **Real-time dispatch** via Socket.IO for new assignments and updates
- **Active assignment card** on Home for in-progress work

### Pickup & delivery tasks

- Step-by-step **pickup workflow** — navigate, contact customer, photo proof, status updates
- Step-by-step **delivery workflow** — handoff, signature, photo proof, completion
- **QR scanner** for fast order verification at pickup and delivery
- **Route guide** carousel for multi-stop guidance
- **Cash payment collection** card when order requires cash at pickup/delivery
- Open destination in **Maps** from task detail

### Earnings & wallet

- **Earnings screen** — daily, weekly, monthly summaries
- **Wallet** — balance, transaction history, withdrawal requests
- **GCash payout** details management
- **Performance** metrics view

### Compliance & profile

- **Document upload** — KYC and compliance tracking
- **Compliance banner** when documents are pending or expired
- Profile edit — name, contact, avatar
- **Support** — in-app contact and help

### Notifications & offline

- In-app **notification inbox** with dispatch alerts
- **Push notifications** when Firebase is configured (production builds)
- **Offline mode** — queue task actions when connectivity is limited; sync when back online
- Offline banner and pending-sync indicators

### Safety

- **SOS button** — emergency alert to dispatch with rider location
- SOS action sheet and session handling

### Authentication

- Sign in with **email and password**
- **Phone OTP** via Twilio (when configured on API)
- Forgot password flow

### Release engineering

- EAS production build pipeline configured
- Monorepo shared packages auto-built via `eas-build-post-install`
- New Architecture enabled (`newArchEnabled: true`)
- Location (when in use + background during shift), camera, and photo library permissions declared

## Build & submit commands

From `apps/rider-mobile`:

```bash
# Verify EAS env/secrets
eas secret:list

# Production builds (both platforms)
npm run eas:build
# or individually:
npm run eas:build:ios
npm run eas:build:android

# Submit latest builds to stores
eas submit --platform ios --profile production --latest
eas submit --platform android --profile production --latest
```

Monitor builds at [expo.dev/eas](https://expo.dev/eas).

## Pre-release checklist

- [ ] `EXPO_PUBLIC_API_URL` points to production API (not localhost)
- [ ] `EXPO_PUBLIC_ENV` = `production` (if used)
- [ ] iOS APNs credentials configured (`eas credentials --platform ios`)
- [ ] Android signing key configured (`eas credentials --platform android`)

- [ ] Root `.easignore` does **not** exclude `apps/rider-mobile`

## Known limitations

- Public self-registration not supported — riders are onboarded by Lunara operations
- Push notifications require production EAS build + Firebase (not Expo Go)
- Store screenshots must be captured manually (no `store-assets` generator yet)
- `package.json` version is `0.1.0` — store-facing version comes from `app.json` / EAS remote
