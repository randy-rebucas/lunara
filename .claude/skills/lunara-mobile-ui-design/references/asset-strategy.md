# Asset Strategy

Classify every visual element as:
- brand
- photograph
- illustration
- standard icon
- custom artwork
- decorative geometry
- native text

Decision:
existing asset → reuse
code/SVG can reproduce → recreate
photographic/custom artwork → real asset
otherwise → reassess

Never use the complete reference screenshot as production UI.

Do not crop screenshot assets by default. If unavoidable, record provenance and mark the asset temporary unless approved.

Organize assets semantically and support white-label brand configuration.
